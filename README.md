# 9도 미소 측정 및 평가 시스템 (Standard 9.00° Smile Metrology System)

> **“친절은 하되 친해지지 마십시오. 감정은 제외합니다.”**  
> — 중앙 통제국 감정관리처 안면 표준 규격 행정 지침 제42호

브라우저 환경에서 단독 구동되는 전시용 안면 미소 계측 및 평가 시스템입니다. 피험자의 얼굴을 실시간 분석하여 표준 규격인 **9.00도 미소**와의 일치율을 절대적·기계적으로 산출하고, 감정이 배제된 공인 검증 기록을 로컬 감사 기록부에 영구 적재합니다.

---

## 1. 시스템 주요 사양

- **구동 플랫폼**: 인텔 iMac의 Windows 환경 (최신 Google Chrome 또는 Microsoft Edge 최적화)
- **로컬 서버**: Node.js 기반 정적 HTTP 서버 (`npx http-server -p 8080`)
- **인공지능 비전 엔진**: MediaPipe Face Mesh (오프라인 로컬 가동 지원, `models/` 내장)
- **영상 입력 규격**: 웹캠 원본 비반전 스트림 (거울 반전 미적용) + 다중 웹캠 장치 전환 지원
- **데이터 보존**: 브라우저 로컬 저장소(LocalStorage) 기반 감사 기록부 (최대 50건 선입선출 유지)

## 2. 실행 방법 (Windows / 인텔 iMac 기준)

### 2-1. 사전 준비사항
1. Node.js (v18 이상 권장) 설치 확인  
   - 터미널(PowerShell / 명령 프롬프트)에서 `node -v` 입력 시 버전이 출력되어야 합니다.
2. 최신 Google Chrome 또는 Microsoft Edge 브라우저

### 2-2. 정적 서버 실행 (Localhost)
프로젝트 루트 폴더(`9digSmile`)에서 터미널을 열고 다음 명령어를 실행합니다.

```cmd
npx -y http-server -p 8080 -c-1
```
*(또는 동봉된 `run-server.bat` 파일을 더블 클릭하여 실행할 수 있습니다.)*

> ⚠️ **[중요] 로컬 저장소(LocalStorage) 오리진 불변성 경고**  
> 브라우저의 보안 정책상 **접속 주소(Origin: 프로토콜 + 도메인 + 포트)가 바뀌면 LocalStorage 기록이 분리되어 초기화**됩니다.  
> `http://localhost:8080`과 `http://127.0.0.1:8080`은 서로 다른 저장소로 취급되므로, **전시 운영 중에는 반드시 항상 동일한 주소와 포트(`http://localhost:8080`)로 실행**하십시오.

---

### 2-3. 키오스크(Kiosk) 모드 전체화면 실행법

전시장 환경에서 주소창, 탭, 시스템 메뉴 등을 모두 숨기고 단독 키오스크 화면으로 띄우려면 다음 명령어 중 하나를 사용하십시오.

#### A. Google Chrome 키오스크 실행
```cmd
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --disable-pinch --overscroll-history-navigation=0 http://localhost:8080
```
- 32비트 Chrome 설치 경로: `"C:\Program Files (x86)\Google\Chrome\Application\chrome.exe"`
- *(동봉된 `run-kiosk-chrome.bat`을 실행하면 시스템 경로를 자동으로 탐색하여 키오스크로 실행합니다.)*

#### B. Microsoft Edge 키오스크 실행
```cmd
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk http://localhost:8080 --edge-kiosk-type=fullscreen
```
- *(동봉된 `run-kiosk-edge.bat`을 더블 클릭하여 실행할 수 있습니다.)*

#### ※ 키오스크 모드 종료 단축키
- **Windows**: `Alt + F4` 또는 `Ctrl + W`
- 키오스크 모드가 아닌 일반 브라우저 창에서 실행했을 때는 화면 우측 상단의 **[전체화면]** 버튼 또는 키보드 **`F`** 키로 전체화면을 토글할 수 있습니다.

## 4. 측정 및 평가 알고리즘

### 4-1. 랜드마크 추출 및 고개 기울기(Roll) 보정
1. **랜드마크 식별**:
   - `LIP_TOP` (0번) 및 `LIP_BOTTOM` (17번): 중점을 계산하여 **입술 중앙 앵커(`lipCenter`)** 확정
   - `MOUTH_CORNER_LEFT` (61번) & `MOUTH_CORNER_RIGHT` (291번): 양 입꼬리 좌표 추출
   - `EYE_LEFT_OUTER` (33번) & `EYE_RIGHT_OUTER` (263번): 양 눈 외안각 좌표 추출
2. **화면 종횡비 왜곡 방지**:
   - 정규화된 좌표(0~1)를 비디오 픽셀 해상도 절대 좌표로 변환하여 종횡비(16:9 등)에 의한 각도 왜곡을 제거합니다.
3. **고개 기울기(Roll) 회전 보정**:
   - 양 눈 외안각을 잇는 벡터의 기울기 $\theta_{\text{roll}} = \operatorname{atan2}(\Delta y_{\text{eye}}, \Delta x_{\text{eye}})$를 산출합니다.
   - `lipCenter`를 회전 중심으로 삼아 안면 랜드마크를 $-\theta_{\text{roll}}$만큼 2D 평면 회전 변환합니다.
   - 이를 통해 피험자가 고개를 기울이더라도 입꼬리 상승 각도가 인위적으로 왜곡되지 않고 정밀 보정됩니다.

### 4-2. 입꼬리 상승 각도 산출
- 회전 보정된 좌표계에서 입술 중앙 대비 양 입꼬리의 수직 상승 높이($\Delta y$)와 수평 거리($\Delta x$)를 계측합니다:
  $$\text{Angle}_{\text{left}} = \operatorname{atan2}(\Delta y_{\text{left}}, \Delta x_{\text{left}}) \times \frac{180}{\pi}$$
  $$\text{Angle}_{\text{right}} = \operatorname{atan2}(\Delta y_{\text{right}}, \Delta x_{\text{right}}) \times \frac{180}{\pi}$$
  $$\text{측정각} = \frac{\text{Angle}_{\text{left}} + \text{Angle}_{\text{right}}}{2}$$

### 4-3. 순수 미소 점수 산출 공식
- **기준각**: $9.00^\circ$ (규격 목표치)
- **감점계수(상수)**: `CONFIG.PENALTY_COEFFICIENT = 10.0` (`js/config.js`에서 손쉽게 조정 가능)
- **점수 산출식**:
  $$\text{Score} = \operatorname{clamp}\left(100 - (|\text{측정각} - 9.00| \times \text{감점계수}),\ 0,\ 100\right)$$
- 9.00도보다 커도(과도한 감정 표출) 감점되며, 작아도(표정 결여/무표정) 동일하게 감점됩니다.

## 5. 측정 흐름 (State Machine)

시스템은 다음 유한 상태 머신(FSM)으로 순환 구동됩니다.

```
[IDLE: 대기]
    │ (안면 감지 성공)
    ▼
[CONSENT: 사진 기록 동의 10초] ──(미선택)──► [IDLE: 측정 취소]
    │ (동의 [Y] / 거부 [N])
    ▼
[COUNTDOWN: 카운트다운 3.0초] ───(안면 소실 시)───► [ABORTED: 오류 경고 및 복귀]
    │ (준비 완료)
    ▼
[MEASURING: 측정 3.0초]       ───(안면 소실 시)───► [ABORTED: 측정 중단]
    │ (초당 30프레임 데이터 수집)
    ▼
[RESULT: 결과 표시]
    │ - 측정 3초간 수집된 점수/각도의 중앙값(Median) 확정
    │ - SUBJECT-XXXX 자동 번호 부여 및 감사 기록부 저장 (동의 시 증명사진 포함)
    │ - 8.0초 후 (또는 스페이스바 입력 시)
    ▼
[IDLE: 대기 복귀]
```

- **안면 소실 안전 장치**: 측정 및 카운트다운 도중 피험자가 이탈하거나 얼굴 인식이 끊어지면 즉각 계측을 중단하고 건조한 안내 문구(`"피험자를 인식하지 못했습니다."`)를 출력한 뒤 대기 상태로 복귀합니다.
- **중앙값(Median) 필터링**: 측정 3초 동안 매 프레임 수집된 점수 배열의 중앙값을 채택함으로써 일시적인 눈 깜빡임, 입술 미세 떨림 등의 노이즈를 줄입니다.
- **동일 피험자 반복 측정 방지**: 결과 표시가 끝난 뒤(또는 동의 미선택으로 취소된 뒤)에는 피험자가 화면에서 1.2초 이상 벗어나야 다음 측정이 시작됩니다. 같은 사람이 바로 다시 하려면 `Space` 또는 화면 클릭. (`REARM_ABSENCE_MS`)

## 5-1. 얼굴 사진 기록 및 개인정보 안내

- **동의 절차**: 얼굴이 감지되면 측정 전 "안면 사진을 감사 기록부에 보관하시겠습니까?" 창이 뜨고, 화면 버튼 또는 `Y`/`N` 키로 선택합니다.
  - **동의**: 결과가 확정되는 순간의 웹캠 프레임에서 얼굴 영역을 증명사진 비율(3:4, 240×320)로 잘라 JPEG로 저장합니다.
  - **거부**: 사진을 아예 촬영하지 않고 점수만 기록합니다.
  - **10초 미선택**: 측정 자체를 취소합니다. (기본값이 '동의'가 되지 않도록)
- **표시**: 결과 카드에 증명사진이 나오고, 하단 기록부의 각 행에 썸네일이 붙습니다. 썸네일을 클릭하면 크게 보입니다 (`Esc` 또는 클릭으로 닫기).
- **저장 위치 및 용량**: 사진은 다른 기록과 함께 브라우저 LocalStorage에만 저장되며 외부로 전송되지 않습니다. 장당 약 10~20KB, 50건 기준 약 1MB로 브라우저 한도(약 5MB) 안입니다. 만약 용량이 부족하면 가장 오래된 기록의 사진부터 삭제되고 점수는 유지됩니다.
- **삭제**: `Shift + R`로 사진을 포함한 모든 기록을 파기합니다. JSON 내보내기 파일에도 사진(base64)이 포함되므로 내보낸 파일도 관리에 주의하십시오.
- **사진 기능 끄기**: `js/config.js`의 `PHOTO.ENABLED`를 `false`로 바꾸면 동의 창 없이 점수만 기록하는 이전 방식으로 동작합니다.

> [!IMPORTANT]
> 얼굴 사진은 개인정보입니다. 전시 현장에도 "촬영 및 게시" 사실과 보관 기간·파기 방법을 안내판으로 고지하고, 전시 종료 후 `Shift + R`로 기록을 파기할 것을 권장합니다. 구체적인 법적 요건은 전시 주최 측에서 확인하십시오.

## 6. 로컬 리더보드 (감사 기록부) 및 단축키

화면 하단에 최근 측정된 피험자의 결과가 실시간 누적 표시됩니다.

- **표시 항목**:
  - 증명사진 썸네일 (동의한 경우만. 클릭 시 확대)
  - 피험자 번호 (`SUBJECT-0001`부터 자동 1씩 증가)
  - 측정 시각 (`YYYY-MM-DD HH:mm:ss`)
  - 측정 각도 (`X.XX°`)
  - 순수 미소 점수 (`XX.X / 100`)
  - 점수 시각화 비교 막대 (100점 만점 기준 규격 일치율 바)
  - 관료적 판정 분류 (`규격 합치`, `허용 범위`, `요주의 안면`, `규격 부적격`)
- **최대 보관 건수**: 최대 50건 유지 (50건 초과 시 가장 오래된 기록부터 선입선출 자동 폐기)
- **영구 보존**: 브라우저를 새로고침하거나 창을 닫았다 다시 열어도 안전하게 보존됩니다.

### 단축키 일람
| 단축키 | 동작 설명 |
| :--- | :--- |
| **`Shift + R`** | **감사 기록 전체 초기화** (사진 포함 모든 누적 데이터 파기 및 번호 리셋 확인 대화상자 호출) |
| **`Shift + E`** | **JSON 감사 데이터 내보내기** (`smile9_audit_registry_...json` 파일로 즉시 다운로드) |
| **`Y`** / **`N`** | 동의 창에서 사진 기록 **동의 / 거부** |
| **`Space`** | 결과·오류 화면 또는 재측정 대기 상태에서 **즉시 복귀 / 빠른 재측정** |
| **`F`** | 전체화면 키오스크 모드 전환 |
| **`M`** | 신호음 소리 켜기/끄기 |
| **`Esc`** | 증명사진 확대 창 닫기 |

## 6-1. 디자인 및 폰트

- 디자인은 동네 전단지 + 노래방 자막 감성(원색 형광, 궁서체 워드아트, 깜빡이는 글씨, 전구 테두리)입니다. 문구는 여전히 감정을 배제한 사무적 어투입니다.
- 폰트는 인터넷 없이 동작하도록 **한국어 Windows 기본 폰트**(궁서, 굴림, 돋움, 맑은 고딕)를 사용합니다. `HY헤드라인M`은 MS Office/한컴오피스가 설치된 경우에만 있으며, 없으면 맑은 고딕으로 대체됩니다.
- Windows 표시 언어가 한국어가 아니면 궁서/굴림이 없을 수 있습니다. `설정 → 앱 → 선택적 기능 → 한국어 보완 글꼴`을 설치하십시오.

## 8. 화면 꺼짐 방지 (Screen Wake Lock)

전시 도중 인텔 iMac 화면이 절전 모드나 화면 보호기로 전환되지 않도록 W3C 표준 **Screen Wake Lock API**가 내장되어 있습니다. 페이지 진입 시 자동으로 화면 활성화 잠금이 적용되며, 상태 표시줄의 `화면 꺼짐 방지: 활성` 표시등으로 동작 여부를 즉시 확인할 수 있습니다.
